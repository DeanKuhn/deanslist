KitchenSync

github ➚ live streamlit app ♕

problem solved

As a Kwik Trip coworker, I use Kwik Trip's Kitchen Production System (KPS) daily. KPS is a food forecasting system designed specifically for Kwik Trip use. While the system excels in a few ways, it is lacking in many others. KitchenSync is designed to directly address these current friction points.

Weather - The current KPS system fails to account for the current weather. Unusually high/low temperatures along with precipitation have a direct impact on customer turnout. KitchenSync uses machine learning to better adjust for common weather patterns.

User Interface - KPS's current UI is not intuitive. While the current KitchenSync Streamlit dashboard mimics the current design, the plan is for an intuitive Next.js framework to replace it. This frontend will display the actual layout of the hot spot, allowing kitchen staff to see visually where food is and when it expires.

Transparency - The current KPS system spits out numbers without any explanation behind them. While experienced staff members may know when a number is incorrect, newer employees may be unaware and follow hallucinated suggestions. KitchenSync plans to solve this problem by incorporating an extremely lightweight NLP system embedded within the Next.js frontend, allowing kitchen staff to ask the system why it is suggesting certain numbers.

results by weather bucket

Bucketing simulated store-days by weather gives a cleaner read than daily A/B comparison. On extreme temperature days, ML beats the baseline by roughly 3x a neutral day gap, clear evidence that it's exploiting the weather signal the baseline can't access.

It's important to note that during simulation, daily temperatures were randomized and do not accurately represent seasonal changes. For example, Monday could be a high of 32° F (0° C) and Tuesday could be a high of 100° F (38° C).

While it can be noted that on rainy/snowy days the ML model's service level is a bit lower than the baseline's, overall waste is nearly half that of the baseline. Clearly, the baseline model over-suggests on rainy days and pays for it with higher waste.
